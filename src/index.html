Free & Open Source

s3pdm

Personal PDM for solo SOLIDWORKS users. Version control, file history, and folder management—backed by affordable cloud storage. No software fees.

Learn More Usage Guide GitHub

Key Features

Folder Tree with Sizes

Browse your vault with a collapsible folder tree. See total folder sizes, modification status, and untracked files at a glance.

Bulk Operations

Select entire folders and check in everything changed inside at once. No more file-by-file management.

Smart Rename & Move

Rename and move files or folders while preserving full history. Works seamlessly with SOLIDWORKS renames and Pack & Go.

File History & Untrack

Full version history for every file. Untrack files safely—history is archived, never truly deleted.

Local Cache

First refresh downloads history once. Subsequent refreshes only fetch changes—fast and efficient.

Any S3-Compatible Storage

Works with Backflaze B2, AWS S3, MinIO, DigitalOcean Spaces, or any S3-compatible provider. No vendor lock-in. Free trials and pay-as-you-go pricing with no software licenses.

Direct File Sharing

Latest versions are stored in the S3 provider's current/ folder. Generate shareable links directly from your cloud provider—no re-upload needed. Send secure URLs to clients or colleagues.

How It Works

s3pdm gives you version control and file history using affordable S3 cloud storage instead of expensive server infrastructure. Your designs are stored reliably without paying for PDM licenses or maintaining your own servers.

The Workflow

  1. Point s3pdm at a folder containing your SOLIDWORKS projects
  2. Check in files—they're uploaded to your S3 storage with full version history
  3. Browse the folder tree, see file sizes and modification status
  4. Rename, move, or untrack files with history preserved
  5. Restore any previous version instantly

System Details

Storage Limits

  • File Size: Up to 5 TB (S3 provider limit) — overkill for SOLIDWORKS
  • SOLIDWORKS Files: Tested with files up to 250 MB
  • Real-World Limit: Your imagination 🚀
  • Free Space: Restore operations need space for temp files
