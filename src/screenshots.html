Screenshots

See s3pdm in action

Folder Tree

Browse your vault with a collapsible folder tree. See total folder sizes, modification status, and untracked files at a glance. Folders are color-coded by status.

Version History

View every check-in, rename, untrack, and restore operation. Click any version to restore it instantly. Full audit trail of all changes.

Log View

Log View shows all the file check ins, with details of the files checked in.

Configuration

Simple settings to configure your cloud storage credentials and vault folder. Supports Backblaze B2, AWS S3, and S3-compatible providers.
